= ByteLabs

image:./.resources/bl.png[ByteLab Logo,150,150]

ByteLabs is a Open-soruce tool for making Byte music.

== Support

=== macOS

the macOS minimum version is `10.15.7`, Catalina. We have also taken into consideration the support
for people below Catalina, but have realised this could cause more bad than good to support a version which we can not even test,
or have a high confidence level to support. It is also the version which GPUI (our gui lib of choice) recomends to have as minimum.

== Contribution

For this project we highly recommend using sometihng which is minimal, due to stuff like vscode and other such forks, with respect
extensions usually come with a formatter and will completley reformat code in a way which we dont want.
So our reccomendation is Zed=editor for something graphical, and any terminal editor with our sugguested LSP's (rust-analyser, nixd, & nil)

What is expected to be used to contribute is the following:

* clippy
* rust-analyser
* rustfmt
* treefmt(-nix)
* nil
* nixd
* cargo
* pkg-config

We also atleast highly motivate the contributers to leverage
the power of Nix, and use the exact same versions of everything
we use, Nix can also get your devenv setup with one command.
