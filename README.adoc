= ByteLabs

image:./.resources/bl.png[ByteLab Logo,150,150]

ByteLabs is a Open-source tool for making Byte music.

== Building

=== Prerequisites

* rust
* cargo
* alsa (linux)
* xdg-utils (linux)
* x11-devel (linux)
* wayland (wayland)
* libxkbcommon (linux)  

== Testing

[source,zsh]
----
RUST_LOG=info cargo r	
----

This will give the most amount of logging.
For more information with `env_logger` please read https://crates.io/crates/env_logger.
